Rearguard aim study
===================

Thank you for taking part. This is a small aiming game for a research study. It
does not connect to the internet and does not install anything.

Starting it
-----------
Unzip this folder anywhere, then:

- Windows: double-click RearguardStudy.exe. The build is not code-signed, so
  Windows may show "Windows protected your PC". Click "More info", then
  "Run anyway". Only do this for a file you received from the study facilitator.
- Linux: run ./RearguardStudy.x86_64 (from a file manager, or a terminal in this
  folder). If it does not start, make it executable: chmod +x RearguardStudy.x86_64

Keep the other file in this folder (the .so or .dll library) next to the program.

The first screen explains the study and what is recorded. If you do not agree,
the game quits and nothing is saved.

At the end
----------
The game shows where it saved one file, named like
rearguard-study-phase1-drift-P-XXXXXXXXXX.zip. Nothing is sent automatically:
you decide whether to send that file to the study facilitator, by hand, in the
way they asked (for example as an e-mail attachment). You can open the zip to
see exactly what it contains.

To remove the game, delete this folder. The exported file is kept in
  Windows: %APPDATA%\Godot\app_userdata\Rearguard Aim Range\exports\
  Linux:   ~/.local/share/godot/app_userdata/Rearguard Aim Range/exports/
until you delete it.
